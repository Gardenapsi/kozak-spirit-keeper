# Kozak Stock Control

Tenho uma cachaçaria artesanal cujo o nome é КОЗАКИ ГОРІЛКА Cachaçaria Artesanal e preciso criar uma aplicação completa para controle de estoque. não se esqueça de criar os bancos de dados, pois o sistema será on-line para acessar de qualquer local e editar coisas informações. no arquivo em anexo, estão todas as opções de cachaças disponíveis com seus respectivos tamanhos de garrafas em ml. a (VODKA Mel com pimenta) ainda não foi lançada. Acredito que o lançamento dessa vodka de mel com pimenta será daqui a 2 meses aproximadamente. preciso também controlar o estoque de itens como garrafas, tampas, rótulos, copos e caixas em madeira para os kits. na segunda imagem anexada, está o cossaco que é a identidade visual da minha marca. preciso que essa aplicação tenha opção de modo escuro e seja responsivo.
